# Verification

Verification uses actual local execution and hosted CI results. See `hosted-verification.json` for the exact published commit, run URLs and conclusions after publication.

The screenshot is generated by the Playwright test against the real application. No API responses are mocked in that browser test. Sample output is generated by the executable CLI on the committed synthetic dataset. Python lifecycle outputs use a fixed clock of 2026-10-30T12:00:00Z for reproducibility. Browser samples use the current clock and fresh IDs.

Run `npm run coverage` for the measured Node report. Test files are excluded; imported production source is included. Unexecuted startup code and HTTP handlers reduce coverage, and browser coverage is not merged into this number.  See `local-verification.json` for observed local checks. Coverage is a measurement of exercised code, not a security or completeness score.

Container smoke checks start the real image with a read-only root, no Linux capabilities and UID 10001, then request its HTTP interface and verify CSP. Browser tests separately exercise actual decisions and negative behavior. These checks do not establish production scalability or correctness of external account permissions.

Live account limitations are documented in the README. Green CI establishes the workflow at its recorded commit only. OPA, Terraform and Semgrep results are generated by real tools where specifically stated; all asset and event data is synthetic.
